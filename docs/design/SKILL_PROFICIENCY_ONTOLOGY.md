# 技能熟练度与训练负荷本体

## 目标

角色通过成功完成行为获得对应技能熟练度，而不是通过重复按键获得。当前接入耕作、近战命中、工具武器命中和成功格挡；采矿、采集、烹饪、制作、钓鱼、动物照料、生存、外交、鉴定与弓术已经作为可扩展技能定义进入目录，后续玩法只需在成功事务提交后调用同一训练接口。

熟练度采用 `0–100` 点与 `L0–L10` 两种显示：`L0` 表示尚未实际练习。掌握阶段为 `untrained → novice → practiced → skilled → expert → master`。

## 人体化训练限制

每项技能独立声明：

- 单次基础收益；
- 每个世界日的基础收益上限；
- 重复训练开始递减的次数；
- 过度训练阈值和扣点系数；
- 同地点/同工具训练负荷的恢复天数。

每次训练同时记录约六米训练格与工具 ID。任一上下文反复出现都会降低收益倍率，并降低该技能当天的有效容量。达到递减后的容量只会停止增长；如果还在相同上下文持续训练并超过负荷阈值，则熟练度下降。默认停止该训练两天后，对应上下文负荷完全恢复；中间休息一天会部分恢复。

每日上限按技能分别计算，换技能不会消耗另一技能的容量。换地点或换工具能够避免局部重复负荷，但不能越过技能本身的绝对每日上限。

## 存档边界

熟练度、每日累计和有限数量的训练上下文保存在现有 Save v4 `player.skills` 中，无需提升存档版本。旧存档只有 `cooldowns` 时会安全读取为全部技能 `L0`。恢复时会限制熟练度、每日累计、上下文数量、负荷和字符串长度，损坏数据不能产生负数、超上限数值或无限增长的存档。

## 知识图谱

技能目录导出为 canonical 世界本体，但玩家的具体数值不属于 canonical 世界事实：

- `skill:* BELONGS_TO concept:skill_domain_*`
- `skill:* PRACTICED_WITH item:*`
- `skill:* PRACTICED_BY concept:practice_action_*`
- `skill:* SYNERGIZES_WITH skill:*`
- `skill:* RECOVERS_AFTER concept:practice_recovery_*_days`

NPC 可以知道世界中存在某种技能及其一般训练方法，但不会自动知道玩家的具体熟练度。NPC 对玩家能力的了解仍需来自亲眼观察、自己的 authored knowledge 或玩家对话告知，保持局部视角。
