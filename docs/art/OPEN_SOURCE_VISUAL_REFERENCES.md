# Stillpoint 3D Visual Reference Notes

The 0.8.x procedural character and environment pass uses original geometry and
materials authored in the Stillpoint codebase. No third-party mesh or texture is
shipped by this pass.

The proportions, readable silhouettes, modular accessories, low-poly material
language, and animation coverage were researched against these permissive
references:

- KayKit Adventurers Character Pack 1.0 by Kay Lousberg
  - Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
  - License: Creative Commons Zero (CC0 1.0)
  - Reference use: compact heroic proportions, equipment silhouette, broad
    idle/walk/combat animation vocabulary.
- Quaternius RPG Characters
  - Source: https://quaternius.com/packs/rpgcharacters.html
  - License: Creative Commons Zero (CC0 1.0)
  - Reference use: role-specific color blocking and readable low-poly faces.
- Quaternius Medieval Village MegaKit
  - Source: https://quaternius.com/packs/medievalvillagemegakit.html
  - License: Creative Commons Zero (CC0 1.0)
  - Reference use: modular timber-and-stone construction, plazas, terraces,
    props, and strong vertical landmarks.

Future binary asset imports must copy the corresponding license alongside the
asset and pass repository/export validation before release.
